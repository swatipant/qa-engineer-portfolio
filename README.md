## How to Run the Python Tests

1. Install Python 3.10 or newer.
2. Open a terminal in the `python-pytest` folder.
3. Install pytest:

   ```bash
   python -m pip install pytest
   ```

4. Run:

   ```bash
   python -m pytest -v
   ```
